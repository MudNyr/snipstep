Works on a computer in Chrome or Edge. Keep this tab open and in front while it scans. It takes about half the video's length, so a 4-minute video takes about 2 minutes. If an ad plays first, let it finish, then press Scan.

How to get a free key (about 5 minutes)
  1. Go to console.cloud.google.com and sign in with any Google account.
  2. Create a project (any name, for example "Snipstep").
  3. Open "APIs & Services", then "Library". Search for "YouTube Data API v3" and click Enable.
  4. Open "Credentials", click "Create credentials", then "API key". Copy the key and paste it above.
  5. Recommended: click the key and, under "Website restrictions", add your Snipstep website address.
